# Modelos de señales ECG / PPG

Este repositorio contiene implementaciones, experimentos y herramientas basadas en modelos matemáticos descritos en publicaciones científicas para la generación y simulación de señales fisiológicas, principalmente señales ECG y PPG.

Las implementaciones incluidas en este repositorio son desarrolladas y mantenidas de forma independiente de las publicaciones originales y de sus respectivas editoriales.

---
